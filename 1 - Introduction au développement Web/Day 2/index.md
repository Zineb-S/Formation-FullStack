# 🏋️ Flexbox Practice Exercise

This exercise will help you learn Flexbox step by step.

## Files
- `index.html` → basic HTML structure with 3 boxes
- `style.css` → starting styles, where you will test Flexbox properties

## Instructions

### 1. justify-content
In `style.css`, inside `.container`, try:
```css
justify-content: flex-start;
justify-content: center;
justify-content: flex-end;
justify-content: space-between;
justify-content: space-around;
justify-content: space-evenly;
```

### 2. align-items
Change vertical alignment by trying:
```css
align-items: flex-start;
align-items: center;
align-items: flex-end;
align-items: stretch;
```

### 3. flex-direction
Switch the main axis:
```css
flex-direction: row;
flex-direction: column;
```

### ⭐ Bonus
- Add more boxes in `index.html`.
- Try combining `flex-direction: column` with `justify-content: space-between` to create a sidebar layout.
